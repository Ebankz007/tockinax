# TOCKINAX USER MANUAL

Fee/reward disclaimers (read first): orders are **recorded, not held** (no escrow);
commissions pay **only on eligible verified sales** (never for recruitment);
activity rewards are **disabled until funded + approved** and are **not returns
on deposits**; crypto/USDT is **disabled** — staff never ask for private keys.

## 1. Register

1. Open the site → **Join the community**. (Screenshot: registration form —
   email, password ≥10 chars, display name, optional referral code, terms checkbox.)
2. Submit. You see the **registration fee disclosure** (default 0/free until the
   business publishes a schedule) and `next: verify_email`.
3. Check email for the verification link (24 h token).

## 2. Verify email

1. Click the link (or paste the token). (Screenshot: "Email verified" confirmation.)
2. Status becomes `pending_verification` → complete any KYC step shown, then wait
   for activation to `active`.

## 3. Apply to sell

1. Profile → **Apply to sell**; submit business/identity details.
2. An admin enables your seller flag. You are notified in-app.

## 4. List an item

1. Seller dashboard → **New listing**: title, description ≥10 chars, category,
   price, currency (USD/NGN), stock, delivery terms. (Screenshot: listing editor.)
2. Submit → status `pending_review`. It appears publicly once an admin approves.

## 5. Order as a buyer

1. Marketplace → open a listing → **Order** → quantity + payment method.
2. The amount is **priced by the server** (`price × qty` + shown 1% platform fee line).
   Anything you type as an amount is ignored.
3. Pay the **seller directly** via the shown instructions (the platform never holds funds).
   Order expires in 48 h if unpaid.

## 6. Submit evidence (screenshot ≠ proof)

1. Order page → **Submit evidence**: provider reference + note (+ receipt file when enabled).
2. Status → `evidence_submitted` (PENDING review). Your order is **not** marked paid yet.
3. Completion happens on provider confirmation or manual review — watch notifications.

## 7. Disputes

1. Order → **Open dispute** with reason (dispute workflow UI ships Phase 3; today via support contact).
2. Statuses: `open → under_review → resolved|rejected`. SLA breaches raise fraud-risk flags for review.

## 8. Referrals

1. Dashboard → **Referrals** shows your code + link (`/register?ref=CODE`), direct invites,
   per-level counts (max 5), and commission totals by status.
2. Commissions calculate only from verified sales after the confirmation period and
   refund window, within budget. Registration fees and transfers never qualify.

## 9. Request a payout

1. Payouts → **Request**: kind (commission/reward), amount, currency, destination
   (bank details). **Never enter private keys or seed phrases** — the form rejects them.
2. Track status in **My payouts** (`requested → under_review → approved → processing → paid`).
   Large payouts need two admin approvals; over-claims return `insufficient_eligible`.
